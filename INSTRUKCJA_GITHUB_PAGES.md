# Instrukcja publikacji — GitHub Pages

## 1. Utwórz repozytorium
Na GitHub:
- kliknij `New repository`,
- Repository name: `budgetflow`,
- Visibility: `Public`,
- możesz zostawić pozostałe opcje domyślne,
- kliknij `Create repository`.

## 2. Wgraj pliki
W repozytorium:
- `Add file`
- `Upload files`
- przeciągnij `index.html`, `.nojekyll` i `README.md`
- na dole kliknij `Commit changes`.

## 3. Włącz GitHub Pages
- `Settings`
- lewa kolumna: `Pages`
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`
- `Save`

## 4. Otwórz stronę
GitHub pokaże adres:
`https://TWÓJ_LOGIN.github.io/budgetflow/`

## 5. Dodaj do Chrome
Otwórz stronę i naciśnij `Ctrl+D`.

## Aktualizacje programu
Przy kolejnych wersjach wystarczy na GitHub podmienić `index.html`.
Adres strony się nie zmieni.
